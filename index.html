Formats

Markdown

Markdown documents with inline formatting and keyboard-first editing.

Notebooks

Notebooks are an infinite canvas for text, images, and freehand drawing.

Stacks

Stacks let you lay documents, notebooks, and PDFs side by side in scrolling columns.

Features

Panes

Panes are floating windows that keep one document in view while you write in another.

Drawing

Draw freehand with brushes, an eraser, and a lasso. Each stroke is an object you can move, group, and layer.

PDF export

Export documents to PDF with typeset styles, line spacing, page numbers, and bibliography support.
