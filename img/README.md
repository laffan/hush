# Images

Drop the landing-page screenshots here. The page references these filenames
(each falls back to a styled placeholder until the file exists):

| File              | Used for                | Suggested size |
| ----------------- | ----------------------- | -------------- |
| `hero.png`        | Hero screenshot         | 1600 × 1000    |
| `markdown.png`    | Markdown format card    | 720 × 480      |
| `notebook.png`    | Notebook format card    | 720 × 480      |
| `stacks.png`      | Stacks format card      | 720 × 480      |
| `panes.png`       | Floating panes feature  | 760 × 480      |
| `drawing.png`     | Drawing feature         | 760 × 480      |
| `pdf-export.png`  | PDF export feature      | 760 × 480      |

PNG or JPG both work. Keep them optimized for web (aim for < 400 KB each).
